# deepseeksearch 开机静默驻留与自启源收敛

> 状态：已完成（2026-11-08）。对应子仓提交：静默唤醒修复 `3a7519b`、审查修复 `acdf293`；发布产物 `deepseeksearch/v1.2.0`。

## 一、现象与根因

**现象**：作为常驻系统托盘的桌面工具，开机后 WebView 主窗口被弹出，违背「静默驻留托盘、按需懒建窗」的设计。

**日志证据**（`%APPDATA%\language_projects\deepseeksearch\prod\deepseeksearch.log`）：2026-11-08 出现两次启动，均写入了 WebUI 启动记录：

- `12:40:23` 第一次启动
- `12:40:54` 第二次启动（约 31 秒后）

**双自启源**：

1. 任务计划程序 `\DeepSeekSearchStudio`（登录触发）
2. 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DeepSeekSearchStudio`

**触发链**：第二实例带 `--hidden` 启动 → 旧代码先打开 SQLite、抢占随机端口 → `application.New` 命中 Wails 单实例锁 → 向首实例投递 `SecondInstanceData` 后退出 → 首实例 `OnSecondInstanceLaunch` 回调**未检查 `data.Args`**，无条件 `ensureMainWindow()` → 把静默驻留的主窗口炸出。

**证据复核（Wails v3.0.0 源码）**：

- `single_instance.go` 的 `notifyFirstInstance()` 直接传 `os.Args`（含 `argv[0]`），因此静默参数解析必须跳过第 0 位。
- `application.go` 中 `logPlatformInfo()` 在单实例检查之前执行，故第二实例日志里出现 Platform Info 不能反证单实例未生效；旧顺序「先开库开端口 → 再被拦截」与日志完全吻合。

## 二、修复内容

| 项 | 实现 | 位置 |
| --- | --- | --- |
| 静默参数单一事实源 | `IsSilentStart`：识别 `--hidden` / `--tray`，跳过 `argv[0]`，大小写与首尾空白容错 | `internal/app/launch_args.go` |
| 第二实例回调识别静默 | 命中静默参数则只记日志并返回，不建窗；非静默才 `ensureMainWindow()` | `internal/app/gui.go` |
| 单实例预检前置 | 将 `application.New` 提到 DB / HTTP 监听之前，第二实例在抢资源前即退出 | `internal/app/gui.go` |
| 入口统一解析 | GUI 入口改用 `IsSilentStart(os.Args)`；CLI 通道同步支持 `--tray` 别名 | `cmd/deepseeksearch/main.go`、`cli.go` |
| 回归测试 | 表驱动 11 例：exe 路径含 `--hidden` 字样不误判、大小写、空白、别名等 | `internal/app/launch_args_test.go` |

## 三、自启源收敛

- **保留**：注册表 `HKCU\...\Run\DeepSeekSearchStudio`，命令行为 `<exe> --hidden`，与托盘菜单「开机自启」的 `Autostart` 状态一一对应。
- **删除**：任务计划 `\DeepSeekSearchStudio`（用户确认属重复源，有意删除；`System32\Tasks` 下已无任务文件，`Get-ScheduledTask` 无匹配）。
- 收敛后开机自启只剩单一入口，完全受托盘菜单控制，不再存在「托盘无法感知的隐藏自启源」。

## 五、遗留与技术债

- **初始化窗口期竞态**：`application.New` 返回后 `appInstance` 立即赋值，但 `serverURL` 要等 DB / HTTP 就绪才写入；该窗口内若收到非静默第二实例唤醒，可能以空 URL 建窗。概率极低，暂不处理。
- **日志先于拦截**：`logf("启动 ...")` 位于单实例检查之前，重复启动时日志必然多一条「启动」行，验收时需以「没有第二条 WebUI 已启动」为判据，避免误判。
- **历史来源不可回溯**：TaskScheduler Operational 日志处于未启用状态，12:40:23 首次启动的具体触发任务已无法从事件日志复核；双源问题随任务删除已闭环，不影响结论。
