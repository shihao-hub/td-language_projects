## 二、发现清单与处置

### WARNING（已全部修复，子仓 commit `acdf293`）

- [x] **W1 时间戳双时区撕裂**：`CURRENT_TIMESTAMP` 写 UTC 墙钟，而缓存 cutoff 用 `time.Now()` 本地时区格式化做字符串比较 → UTC+8 下 24h 窗口漂移 ±8h；回读无时区导致前端/CLI 显示 UTC 墙钟。
  修复：`sqlite.go` 收敛 `dbTimeLayout` 常量 + `dbCutoff()`（`time.Now().UTC().Add(-maxAge)`）+ `parseDBTime()`（`ParseInLocation UTC`，兼容 RFC3339 历史）；CLI/前端展示层转本地时区。
- [x] **W2 吞错静默错效**：缓存读取/历史写入/GetConfig 全吞噬——DB 故障时静默 miss 直打付费 API（恰是"0 元消耗"设计要防的）；GetConfig 失败伪装成"未配置 Key"。
  修复：server 侧 `log.Printf` 留痕后继续 miss；CLI 侧 stderr 警告；历史写入失败 `log`/stderr 留痕；GetConfig 失败按真实错误终止并退出。
- [x] **W3 缓存条数契约错位**：`WHERE count >= ?` 宽缓存允许请求 10 条命中 50 条记录。
  修复：`GetCachedSearch` 命中侧统一截断 ResultsJSON 至请求条数并同步 ResultCount（`truncateResultsJSON`），"返回结果数 == 请求条数"契约成立。
- [x] **W4 HTTP 响应无大小上限**：`io.ReadAll(resp.Body)` 无界读取，异常 BaseURL 可 GB 级响应 OOM。
  修复：`io.LimitReader` 10MB 上限，超限报"响应体超过 10 MB 上限"。
- [x] **W5 localhost API key 双路径暴露 (a)**：无 Host 校验 → DNS rebinding 后恶意页面以"同源"身份读改配置。
  修复：`localHostGuard` 中间件，`net.SplitHostPort` 后 Host 白名单仅放行 `localhost`/`127.0.0.1`/`::1`，其余 403。
- [x] **W6 markdown 链接 href 无 scheme 白名单**：`formatInline` 生成 `<a href="$2">`，外部网页正文中 `[](javascript:...)` 直通；`fetchSourceLink.href` 同理。
  修复：前端 `safeUrl(u)` 非 `http(s)://` 一律返回 `#`，套用于 formatInline 链接、结果卡 href/data-url、fetchSourceLink.href。
- [x] **W7 零测试回归缺口**：新公共函数 `IsSilentStart`（"两处共用单一事实源"）与单实例新守卫分支无回归测试。
  修复：新增 `launch_args_test.go`（表驱动：argv[0] 路径含 `--hidden` 字样不误判、大小写混合、空白、命中/不命中共 11 例）。
