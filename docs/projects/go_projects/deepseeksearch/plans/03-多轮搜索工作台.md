# 多轮搜索工作台

状态：实施中。依据用户确认的「搜索词工作台 → 多路搜索 → 根据反馈补搜」。

## 交付范围

- GUI 与 CLI 共享研究 Service；已有单次搜索与抓取兼容。
- 研究记录自动保存，支持关闭后恢复、跨入口继续。
- 复用 DeepSeek Key/BaseURL，模型可设置，默认 deepseek-flash。
- AI 只按按钮生成可编辑建议，不自动勾选或执行。
- 每轮最多 6 路，默认每路 10 条，并发 3 路；每路 60 秒、整轮 150 秒。
- URL 去重、排名融合、来源追踪、本轮新增标记；反馈支持预设及自由文本。
- 部分失败保存已有结果，取消与中断后手动重试；数据库租约保护跨进程修改。
- 新命令人读、JSON 包络与离线 Schema；原命令输出兼容。
- SQLite 增量迁移前备份；研究缓存覆盖原始意图、地域、来源与正文需求。
