# 需求说明

## 摘要

新建 Go CLI 工具 `sourcecount`，用于统计一个或多个项目目录中的源码文件。工具按文件后缀聚合结果：文本文件统计文件数、逻辑行数和 Unicode code point 字符数；二进制文件统计文件数和文件大小。工具支持 JSON 配置文件过滤目录/文件，并通过公共 Server 层同时服务 CLI 与 MCP。

## 功能需求

- 支持扫描一个或多个文件或目录根路径；未指定根路径时使用当前工作目录。
- 目录递归扫描，默认不跟随 symbolic link、junction 和其他 reparse point；同一规范化路径只统计一次。
- 后缀取最后一个扩展名并转为小写；无扩展名文件归入 `<none>`。
- 支持 `.sourcestats.json` 配置文件，配置 include/exclude Glob、默认排除开关、文本后缀覆盖和二进制后缀覆盖。
- include 先缩小候选范围，exclude 最终否决；支持 `*`、`?`、字符类和跨目录 `**`。
- 默认排除常见版本库、依赖、构建和缓存目录，并支持 `--no-default-excludes` 关闭。
- 文件类型判定优先使用配置覆盖；未覆盖时使用内容探测：包含 NUL 或无效 UTF-8 判为二进制，否则判为文本。
- 文本文件按流式方式统计逻辑行数与 Unicode code point 字符数；强制文本时无效 UTF-8 以替换字符继续统计。
- 二进制文件只读取文件元数据获取字节大小，不加载完整文件内容。
- 结果按后缀聚合并提供总计；同一后缀允许同时存在文本和二进制统计。
- CLI 提供人读输出、稳定 JSON 输出、`schema` 导出、版本和帮助命令。
- CLI 的 `mcp` 子命令启动 stdio MCP server；MCP 工具与 CLI 调用同一公共 Server 层。

## 非功能需求

- 运行期间不创建数据库、缓存、日志或其他持久化业务文件。
- 大文件采用流式读取；扫描并发有界，结果和错误顺序稳定。
- 配置和参数错误返回退出码 `2`；单文件读取错误允许部分完成，结果携带错误并返回退出码 `1`。
- `schema`、`--help` 和 `--version` 不触发扫描或业务文件读取。
- 公共业务层不直接操作 stdout、stderr 或调用 `os.Exit`；CLI/MCP 负责渠道适配。

## 验收标准

### AC-1 扫描边界

给定多个根路径时，工具递归统计所有符合过滤规则的文件；重复传入同一规范化路径只统计一次；链接目录和链接文件默认跳过。

### AC-2 后缀聚合

`foo.TS` 和 `bar.ts` 聚合为 `.ts`；单独点文件归入 `<none>`；输出按后缀稳定排序并包含总计。

### AC-3 文本统计

空文件为 0 行；`a` 与 `a\n` 都为 1 行；CRLF、LF 和单独 CR 均正确处理；中文和 emoji 按 Unicode code point 计数。

### AC-4 二进制统计

二进制结果包含文件数和字节数，不需要读取完整内容；同一后缀的文本和二进制文件可以分别聚合。

### AC-5 过滤与配置

配置文件能够表达 include/exclude Glob、默认排除开关和后缀类型覆盖；include 先缩小范围，exclude 最终否决；CLI 显式参数覆盖配置文件对应项。

### AC-6 配置发现

显式 `--config` 优先；否则依次查找当前工作目录和单根目录下的 `.sourcestats.json`；多根目录不合并多个配置文件；没有配置时使用内置默认值。

### AC-7 部分失败

单个文件 stat/open/read 失败时继续扫描，并在结果的 `errors` 中记录安全错误信息；整体 JSON 为 `ok=false`，退出码为 `1`。

### AC-8 CLI 契约

CLI 默认输出人读表格；`--json` 输出合法的 `{"ok":true,"data":...}` 或部分失败的 `{"ok":false,"data":...,"error":...}`；参数错误返回 `error.code` 和退出码 `2`。

### AC-9 MCP 契约

`sourcecount mcp` 使用 stdio 启动 server，注册 `sourcecount.project.scan` 工具；工具输入、结果和错误语义与公共 Server 层及 CLI JSON 契约一致。

### AC-10 离线 Schema

`sourcecount schema` 输出与 MCP 工具注册同源的静态 JSON 契约，且不扫描目录、不读取业务配置、不启动文件统计。

## 范围外

- 不实现 GUI、HTTP daemon、远程文件扫描或持久化历史记录。
- 不输出单文件明细；本期只提供按后缀聚合和总计。
- 不解析 `.gitignore`；过滤规则仅来自内置默认值、JSON 配置和显式 CLI 参数。
- 不计算文本文件字节数、注释行数、空白行数或代码复杂度。
