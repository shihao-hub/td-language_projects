# sourcecount 使用指南

## 工具定位

`sourcecount` 是独立的 Go CLI/MCP 工具，用于按文件后缀统计项目源码。CLI 与 MCP 都调用 `internal/service.Server`，扫描、配置、类型判定和聚合逻辑保持同源。

## 构建

在 `go_projects/sourcecount` 目录执行：

```powershell
go build ./...
uv run scripts/build.py --version 1.0.0
```

构建脚本输出 `build/sourcecount.exe`，默认开发版本为 `dev`。

## CLI 调用

```powershell
sourcecount.exe                         # 扫描当前目录
sourcecount.exe . src                  # 扫描多个根路径
sourcecount.exe --json .                # 输出 JSON 包络
sourcecount.exe --pretty --json .       # 缩进 JSON
sourcecount.exe --config .sourcestats.json .
sourcecount.exe --no-default-excludes .
sourcecount.exe schema                  # 导出 MCP Schema
sourcecount.exe mcp                     # 启动 stdio MCP server
```

参数错误返回退出码 `2`；单个文件无法读取时继续扫描，输出部分结果并返回退出码 `1`。

默认人读输出包含：后缀、文本文件数、文本行数、文本字符数、二进制文件数和二进制字节数。JSON 结果使用：

```json
{
  "ok": true,
  "data": {
    "roots": [],
    "groups": [],
    "totals": {
      "text": {"files": 0, "lines": 0, "chars": 0},
      "binary": {"files": 0, "bytes": 0}
    },
    "errors": []
  }
}
```

## 配置文件

文件名固定为 `.sourcestats.json`。加载优先级：

1. `--config` 显式路径；
2. 当前工作目录的 `.sourcestats.json`；
3. 单根目录的 `.sourcestats.json`；
4. 内置默认值。

多根路径不合并多个配置文件。配置文件未知字段会被拒绝，`version` 缺省按 `1` 处理。

```json
{
  "version": 1,
  "include": ["**/*.go", "cmd/**"],
  "exclude": ["**/generated/**"],
  "text_extensions": [".tmpl"],
  "binary_extensions": [".dat"],
  "default_excludes": true
}
```

- `include` 非空时只保留匹配文件、匹配目录及目录后代。
- `exclude` 最终否决匹配项；目录命中后剪枝整棵子树。
- `*`、`?`、字符类匹配单个路径段，`**` 匹配零个或多个路径段。
- 后缀覆盖大小写不敏感；缺少前导点时自动补充。
- 同一个后缀不能同时出现在 `text_extensions` 和 `binary_extensions`。
- CLI 的重复 `--include`、`--exclude`、`--text-ext`、`--binary-ext` 会替换配置文件中的对应列表。

默认排除：`.git`、`.hg`、`.svn`、`node_modules`、`vendor`、`dist`、`build`、`target`、`.idea`、`.vscode`、`.venv`、`__pycache__`、`coverage`。

## 类型与统计口径

- 文件后缀取最后一个扩展名并转小写；单独点文件归入 `<none>`。
- 配置后缀覆盖优先于内容探测。
- 未覆盖文件含 NUL 或不是有效 UTF-8 时按二进制处理；否则按文本处理。
- 文本字符数按 Unicode code point 统计，换行符也计入字符数。
- 空文件为 0 行；`a` 与 `a\n` 都是 1 行；CRLF、LF 和单独 CR 都算一个逻辑行边界。
- 二进制只统计文件数量和元数据中的字节大小。
- 默认不跟随 symbolic link、junction 和其他 reparse point；多个根路径命中同一规范化文件时只统计一次。

## MCP

MCP 使用本地 stdio：

```json
{
  "mcpServers": {
    "sourcecount": {
      "command": "sourcecount.exe",
      "args": ["mcp"]
    }
  }
}
```

工具名为 `sourcecount.project.scan`。输入字段与 CLI 业务参数一致，输出为同一份 `ScanReport`。扫描部分失败时 MCP 结果标记为工具错误，同时保留结构化报告和 `errors`。

## 不在本期范围

- GUI、HTTP daemon、远程扫描、历史数据库和缓存。
- 单文件明细、Git 历史、注释行、空白行、文本字节数和 AST 复杂度。
- `.gitignore` 语义；过滤只来自内置默认值、JSON 配置和 CLI 参数。
