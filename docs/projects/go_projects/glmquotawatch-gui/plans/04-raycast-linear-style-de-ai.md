# Plan: glmquotawatch-gui 视觉与体验“去 AI 味”高级重构（Raycast/Linear 质感浅色桌面风）

## 问题陈述与背景

当前 `glmquotawatch-gui` 在经历了浅色化（03号方案）和横向窗口调整（02号方案）后，虽然脱离了暗色荧光绿，但整体视觉结构依然具有典型的“AI 模板味”：
1. **配色平铺无层次**：背景与卡片虽然为浅灰与纯白，但缺乏细腻的微对比（没有微质感、缺乏景深与精细阴影），大量使用默认的纯平色块；
2. **布局规整但呆板**：居中大卡片、三等分、对称流，缺乏 Linear / Raycast 那种高级桌面工具的“信息节奏感”（非对称重点、紧凑与开阔对比）；
3. **文案刻板**：部分状态提示依然偏向机械式的系统日志，缺少富有温度、口语化但严谨的具体人话；
4. **组件与微交互生硬**：进度条、滑块、徽标为最基础的 CSS 默认效果，缺乏原生桌面工具的微交互（柔和悬浮响应、微质感边框 highlight、更高级的数字排版）；
5. **ECharts 呈现常规**：图表仍然是传统的纯色折线 + 简单半透明填充，没有现代工具中常见的精准数据微光刻度与精致 Tooltip。

参考《7个神级技巧彻底去除网站AI味》（程序员鱼皮），本方案贯彻：
- **明确设计主张**：Raycast / Linear 质感的高级浅色桌面工具调性——精致双层边框（1px 内外光影）、微弱冷灰冷白层级、非对称节奏感排版、极致精细的数字与单位微排版；
- **反向禁止清单**：坚决禁止蓝紫渐变、坚决禁止平庸三卡片并排与僵硬对称、禁止粗糙纯平边框、禁止空洞模板式文案；
- **自主精确色系**：弃用预设色板，建立专门的高级纸质/金属质感微灰调与深邃点缀绿；
- **保持零大型外置依赖**：纯自研 Tailwind CSS + 精巧 SVG，保障 Wails 3 极速冷启动与离线桌面体验。

## 需求（用户决策确认）

- 风格主张：延续浅色桌面工具调性，追求 Raycast / Linear 质感，深化留白、非对称排版与精致微对比（1=a）；
- 交付范围：全流程落地，编制方案与实施清单，获批后对前端页面与组件进行完整重构（2=a）；
- 依赖策略：纯自研 Tailwind CSS + 精简内联/通用 SVG，不引入外部庞大图标或组件库，保持轻量（3=a）。

## 方案设计

### 1. 颜色与微质感体系（Design Tokens）

在 `frontend/src/style.css` 中重设 `@theme`，引入多层微灰阶与多层光影阴影：

| 语义变量 | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#f4f6f5` | 整体应用底色（带极其微妙冷绿调的高级哑光灰） |
| `--color-panel` | `#ffffff` | 主容器/卡片背景（纯净白） |
| `--color-panel-hover`| `#fafbfa` | 卡片/交互项悬浮态微光 |
| `--color-well` | `#eaeef0` | 凹槽轨道、输入框微沉底色 |
| `--color-edge` | `#e1e6e3` | 基础描边（柔和轻量） |
| `--color-edge-strong`| `#d0d7d3` | 强调描边、分隔线、焦点外框 |
| `--color-brand` | `#0d9468` | 核心健康态翡翠绿（比纯 emerald 更深邃、更具桌面工具高级感） |
| `--color-brand-light`| `#e6f5ef` | 品牌高光胶囊底色 |
| `--color-warn` | `#c25e00` | 预警琥珀色（文字与高对比描边） |
| `--color-warn-light`| `#fef3e6` | 预警胶囊底色 |
| `--color-crit` | `#be123c` | 紧急赤红（玫瑰红调，避免大红造成的廉价刺眼感） |
| `--color-crit-light`| `#fef1f2` | 紧急胶囊底色 |
| `--color-ink` | `#111827` | 主标题与关键指标（深冷碳灰） |
| `--color-dim` | `#4b5563` | 正文与常规说明 |
| `--color-faint` | `#8b97a2` | 辅助标注、失效占位、时间戳 |

**质感提升手段**：
- **微阴影体系**：摒弃单一模糊阴影，使用双层阴影 `box-shadow: 0 1px 2px rgba(15,23,42,0.04), 0 4px 12px rgba(15,23,42,0.03)`，营造轻薄浮雕感；
- **内发光描边（Inset Highlight）**：卡片与按钮顶部带 1px 极微白光 `box-shadow: inset 0 1px 0 rgba(255,255,255,0.7)`，模拟 macOS 原生金属/磨砂质感；
- **更讲究的等宽排版**：数字与关键代码全面应用 `.tnum` 与字符间距微调（`tracking-tight`）。

### 2. 界面结构与节奏感重构（去模板味）

- **顶部导航（`App.vue`）**：
  - 左侧品牌区：由简单的文字升级为具备桌面小工具特征的状态微标（带有精密状态呼吸小点 + 微徽标）；
  - 右侧 Tab：由普通分段按钮升级为带平滑交互质感、紧凑高效的工具切换条；
- **仪表盘核心（`Dashboard.vue` + `UsageCard.vue`）**：
  - 彻底重构大卡片千篇一律的居中样式，改为**非对称主从结构**：左侧突出巨大的当前消耗百分比与动态速率（人话具象文案），右侧紧凑排列重置周期与告警阶梯；
  - 进度条不仅是一根色条，而是带精致刻度标记与当前水位指针的微型仪表；
  - 空态/等待态文案彻底去 AI 模板味，使用具体、清晰且自然的对话语气（例如：“上游暂未下发窗口数据，监控将在后台保持静默重试”）。
- **历史走势（`History.vue`）**：
  - ECharts 图表样式升级：采用极简高定色调，移除廉价大面积高透明度渐变，改为细腻柔和的面积微晕与点阵参考网格；
  - 顶部筛选器升级为极简按键胶囊，摒弃原生粗糙的 `<select>` 外观。
- **设置页（`Settings.vue`）**：
  - 分组不再是千篇一律的大白块，而是类似 Linear 的设置清单列表：左侧精练说明，右侧内联操作，配置更紧凑高效；
  - 更加平滑细腻的交互反馈与就地提示。
