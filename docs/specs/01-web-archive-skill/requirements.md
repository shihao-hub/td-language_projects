# Requirements Document

## Summary

做一个可复用的 Skill（暂定名 `sh-web-archive`，用 skill-creator 创建）：给定公开网页 URL，先筛选"无需鉴权"的页面（需要登录/Cookie 的明确拒绝、不做），抓取正文与全部多媒体资源（文字/图片/音频/视频），本地化保存为**静态 HTML 存档目录**（非单文件），页面左侧提供三个 tab 切换：**原文、AI 总结、可编辑页面**。AI 总结由会话中的模型撰写，遵守"去 AI 味"写作与排版纪律。首个目标文章：《刚刚，全网刷屏的 Jev 模型正式开放！一手实战测评 + 保姆级教程》（https://mp.weixin.qq.com/s/tKzLooBWfsNQ3xcFVQOjCw ，已验证无需鉴权可匿名访问）。产物统一存放于 `%APPDATA%\agents-skills\{skill_name}\` 下。

## Functional Requirements

- FR1 **鉴权筛选**：输入 URL 后先匿名请求；能取到正文则继续；检测到登录墙、403、需 Cookie/Token 鉴权等情形则明确拒绝并给出清晰错误信息，不产出半成品目录，不尝试任何绕过。
- FR2 **正文抓取**：提取网页的标题、作者/公众号名、发布时间与正文文字，保留原文结构（标题层级、段落、代码块、表格、引用、链接）。
- FR3 **多媒体保留**：正文中的图片、音频、视频资源下载到存档目录并改为本地引用；无法下载的媒体（如外站 iframe 嵌入的视频）保留原始嵌入方式与原文链接，并给出明确占位说明，不静默丢弃。
- FR4 **静态目录产物**：`%APPDATA%\agents-skills\sh-web-archive\` 为根目录，**每次存档任务（一个网页）一个子目录**（命名"日期 + 标题"）；子目录内为 `index.html` + `assets/`（本地化资源）+ `history/`（编辑历史版本快照），不要求单文件内嵌。
- FR5 **三 tab + 子 tab 交互**：页面左侧为 tab 导航，共三个：**原文**（忠实渲染原文）、**AI 总结**（模型撰写的总结）、**可编辑页面**（浏览器内编辑内容并保存，修改持久生效）。主 tab 可自由切换，当前项高亮。**每个主 tab 下有子 tab 行**，展示该 tab 内容的编辑历史版本，倒序排列（最新的在第一个），默认选中最新版，点选子 tab 可查看任意历史版本。
- FR6 **版本化编辑历史**：每次编辑保存生成一个带时间戳的不可变版本快照，存于该存档的 `history/` 下并归属对应主 tab；历史版本只增不改不删，重开页面后历史仍在。
- FR7 **AI 总结**：模型通读原文后撰写结构化总结，内容与原文事实一致、不编造；写作风格遵守 skill 内维护的"去 AI 味"设计规范（参考鱼皮《7个神级技巧去AI味》与 sh-lark-chat-archive 的 design-rules）。
- FR8 **Skill 化**：按 skill-creator 规范产出 `SKILL.md` + `scripts/` + `references/`，成为可复用 skill；职责分离——脚本管确定性抓取/下载/渲染，模型管语义（读原文、写总结、把握审批门）。

## Non-Functional Requirements

- 排版遵守"去 AI 味"纪律：纸面质感、非蓝紫渐变、不以 Emoji 作功能图标、文案具体化（细则在设计阶段从参考文档落入 skill 的 references）。
- 纯静态：`file://` 直接打开即可用，无构建步骤、无外部 CDN 依赖，完全离线可看。
- 脚本用 Python + PEP 723 内联元数据，`uv run` 执行（对齐既有 skill 脚本模式）。

## Acceptance Criteria

### AC-1 存档产出
给定 Jev 文章 URL，运行 skill 后在 `%APPDATA%\agents-skills\sh-web-archive\` 下产出**本次任务专属子目录**（命名"日期 + 标题"），内含 `index.html` + `assets/` + `history/`；浏览器以 `file://` 打开 `index.html` 正常显示。之后存档另一个网页时生成另一个同级子目录，互不干扰。

### AC-2 原文完整性
原文 tab 完整呈现文章：文字无缺失段落，图片从本地加载成功，代码块/表格结构保留；无法本地化的媒体有明确占位与原文链接。

### AC-3 总结质量
AI 总结 tab 呈现模型撰写的结构化总结；抽查总结中的关键事实（如响应速度对比、三种问题类型、价格数据）均与原文一致，无编造。

### AC-4 可编辑持久化与历史
可编辑页面 tab 中修改文字并保存后，关闭再重新打开该存档，修改仍在；且本次保存生成一条新的不可变历史版本，对应主 tab 的子 tab 列表最前面出现该版本，点选子 tab 能查看该历史版本内容。

### AC-5 三 tab + 子 tab 切换
左侧三个主 tab（原文 / AI 总结 / 可编辑页面）可自由切换，当前项高亮；各主 tab 下的历史子 tab 倒序排列（最新在第一个），点选子 tab 可切换查看对应版本，内容正确对应。

### AC-6 鉴权拒绝
对一个需要鉴权的 URL（登录墙/403）运行工具，得到明确的拒绝错误信息，不产出任何半成品目录。

### AC-7 可复用性
换一个无需鉴权的 URL（非微信生态亦可）再次使用该 skill，不改代码即可完成全流程（抓取 → 资源本地化 → 总结 → 三 tab 页面）。

## Out of Scope

- 需要登录、Cookie、验证码的页面：明确不做，也不做任何鉴权绕过。
- 音视频转码、压缩、格式转换：原样保存。
- 单文件 HTML 产物形态：明确为目录形态。
- 服务端程序、构建流程、外部 CDN：纯静态，不做。
- 把存档发回飞书/消息转发等分发动作：不在本 skill 范围。

## 假设标注（待确认）

- **A1 产物根路径**：按用户指定为 `%APPDATA%\agents-skills\{skill_name}\`，即 `%APPDATA%\agents-skills\sh-web-archive\`（不套 `language_projects` 一层；与 AGENTS.md 通用数据约束不同，以用户本次指定为准）。
  > **变更记录（2026-09-21，执行阶段）**：实测 Chrome showDirectoryPicker 拒绝选择带隐藏属性目录链（AppData 默认 Hidden，报"包含系统文件"），编辑授权无法完成；经用户确认迁至 `~\agents-skills\sh-web-archive\`（用户主目录），FR4 的"%APPDATA%"表述以本变更为准。
- **A2 skill 命名**：暂定 `sh-web-archive`（对齐 `sh-lark-chat-archive` 命名习惯），批准时可改。
- **A3 可编辑范围与历史归属**：三个主 tab 的内容均可编辑留痕——"可编辑页面"为编辑入口（可编辑原文转录、AI 总结或自由补充内容），保存时按被编辑内容生成版本快照并归属对应主 tab（原文历史归原文、总结历史归总结）；各主 tab 始终展示其内容的最新版，历史版本经由该 tab 的子 tab 查看。"可编辑页面"自身的子 tab 为全部编辑动作的时间线（同样倒序）。交互细节设计阶段定。
- **A4 AI 总结来源**：由会话中的模型（我）直接撰写，不调用外部 AI API。
