## 问题陈述

存档页 `docs/repo/lark_group_bridge/2026-09-20 自言自语存档.html` 是纯静态只读文件，用户想删掉/修改其中部分内容（消息、图注、编后记），需要页面内编辑能力，且编辑结果要能持久化回文件本身。

## 需求

用户原话："能不能支持编辑啊？html 编辑。。。有些内容我想删掉。"

**需求修正（2026-09-21 用户测试反馈）**："我要修改的是每条消息的内容。比如删减几个字" —— 核心需求是**每条消息正文可自由删改字句**，整条删除是次要能力。原实现的理解偏差 + 入口失效导致用户完全未能体验改字能力。

执行时 agent 自拟的默认设计（未经用户确认）：
- **改（核心）**：每条消息正文（含图注）进入编辑态后可点击定位、自由删改字句
- **删（次要）**：转录区每条消息可整条删除（一张图 = 一条）；编后记按节删除；带撤销栈
- **存**：序列化整页 → 优先浏览器「另存为」覆盖原文件，退化时下载后手动替换；保存后的文件保留编辑能力
- 统计（条数/图数）保存时自动重算

- 目标文件：`docs/repo/lark_group_bridge/2026-09-20 自言自语存档.html`（2.66 MB，20 图 base64 内嵌，已含 lightbox 与图注）

- AOCI：该文件 Entry 已随本次改动更新并对齐

## 方案

纯原生 JS 编辑器（无外部依赖，file:// 离线可用）：
1. 侧栏新增「编辑此页」入口 → 进入编辑态（body.editing）
2. 每条 `.msg` 注入「删除本条」按钮；编后记每个 `h3` 注入「删除本节」（含节下段落）；删除入撤销栈可逐步恢复
3. 正文 `.txt` 与图注 `p.imgcap` 置 contenteditable
4. 底部工具条：撤销删除 / 放弃修改（重载）/ 保存修改
5. 保存：清编辑态 UI → 重算统计 → 重置 lightbox 临时态 → `documentElement.outerHTML` 序列化 → `showSaveFilePicker` 覆盖原文件（失败则 blob 下载）
