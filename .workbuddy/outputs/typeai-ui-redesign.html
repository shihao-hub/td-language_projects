Java 中的 Instant

一句话定义

Instant（java.time.Instant，Java 8 引入）表示时间轴上的一个绝对时刻，内部就是「从 1970-01-01T00:00:00Z（Unix 纪元）起经过的秒数 + 纳秒数」。

它没有时区、没有日历概念，就是一个纯粹的"时间戳"，用来给机器看，而不是给人看。

基本用法

java第 2 段 · 共 3 段
Instant now = Instant.now();          // 当前时刻（UTC）
Instant t = Instant.parse("2026-10-24T09:06:23Z");
Instant later = now.plusSeconds(90);  // 秒 / 纳秒算术
long epochMilli = now.toEpochMilli(); // 转毫秒时间戳
