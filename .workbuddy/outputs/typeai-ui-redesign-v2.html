typeai UI 细化方案 v2 · 动态标签方向

像素君 · 顺延「动态标签池 + 树状分组 + 偏好持久化」最新实现 · 2026-10-24

① 对照你最新布局的四个细化点

  • 消除徽标冗余（最重要）：会话在「待办」组里还挂「待办」徽标、「归档」组里挂「已归档」——组头已表达的信息在卡内重复。规则：卡内徽标只渲染组头未表达的标签（即 otherTagMap 里的动态标签），渲染逻辑只需在 renderSessionCard 里传入当前组 id 过滤一次。
  • 时间戳降噪：2026/10/24 18:26:45 秒级时间戳改为相对时间阶梯——今天显 18:26、昨天显「昨天」、本周显「周三」、更早显 10-08。列表扫读效率显著提升，hover 时 title 属性保留完整时间。
  • 动态标签配色：当前动态标签徽标全部灰白，与「未分类」无法区分。引入 8 色低饱和稳定色板，按标签名 hash 取色（同一标签在组头色点 / 卡内徽标 / pill / 标签池四处永远同色）。见下方色板。
  • 搜索入口：未分类 23 条且会持续增长，侧栏顶部加搜索框（Ctrl+K），命中范围：标题 + 标签。这是标签体系成立后的自然补全。

  • 颜色只做 tint（12%~18% 背景 + 30% 边框 + 纯色文字/圆点），全部基于 color-mix，明度一致，不抢内容。
  • 同一标签四端同色：树状组头圆点 → 卡内徽标 → 会话属性 pill → 全库标签池 chip，形成「标签=颜色」的心智映射。

③ 其余增量

  • 空状态升级：一句话 → 品牌占位 + 快捷键提示（Ctrl K 搜索 / Ctrl N 新建），首次使用即可发现搜索。
  • Composer 聚焦光晕：现有 focus-within 描边升级为 box-shadow: 0 0 0 3px accent-soft 光晕；发送按钮改琥珀实底，主行动更醒目。
  • 对比度修正：--text/--muted/--faint 各提亮一档，--faint 从 4.6:1 以下拉到 AA 达标（4.6:1）。
  • 运行态 Tab：.running 的 "*" 后缀升级为呼吸圆点。
  • 活动会话指示：active 卡左缘 3px 琥珀条，与置顶 ⚲ 图标双编码不冲突。

④ 落地路径（映射到现有代码）

  • 纯样式项（token 提亮、光晕、空状态、发送按钮）→ 只改 style.css，半小时级。
  • 徽标去冗余 → app.js renderSessionCard(item, currentSessionID) 加一个 groupTag 参数过滤，10 行内。
  • 相对时间 → formatRelative(ts) 工具函数替换 meta 渲染，注意保留 title 完整时间戳。
  • 标签色 → 新增 tagColor() + CSS 变量注入（style="--tag-c:..."），四处渲染点各一行。
  • Ctrl+K 搜索 → 需要新的过滤态，建议独立小任务排期。
