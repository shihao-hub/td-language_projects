## 📝 题目重现
> **题目**：$\text{Cl}_2$ 在 $70^\circ\text{C}$ 的 $\text{NaOH}$ 水溶液中能同时发生两个自身氧化还原反应，生成的产物为 $\text{NaClO}$、$\text{NaClO}_3$、$\text{NaCl}$。反应完全后，测得溶液中 $\text{NaClO}$ 与 $\text{NaClO}_3$ 物质的量之比为 $5 : 1$，则溶液中 $\text{NaCl}$ 与 $\text{NaClO}_3$ 的物质的量之比为 _________。

**【参考答案】**：**$10 : 1$**（或填 $10$）

---

## 🎯 核心解题方法：特值赋值法 + 得失电子守恒

### 1. 标明化合价变化（确定升降）
- 反应物：$\text{Cl}_2$（$\text{Cl}$ 为 $0$ 价）
- 氧化产物（失电子，化合价升高）：
  - $\text{NaClO}$（$\text{Cl}$ 为 $+1$ 价，每个 $\text{Cl}$ 升高 $1$）
  - $\text{NaClO}_3$（$\text{Cl}$ 为 $+5$ 价，每个 $\text{Cl}$ 升高 $5$）
- 还原产物（得电子，化合价降低）：
  - $\text{NaCl}$（$\text{Cl}$ 为 $-1$ 价，每个 $\text{Cl}$ 降低 $1$）

### 2. 巧妙赋值（消除抽象未知数）
已知题目条件 $n(\text{NaClO}) : n(\text{NaClO}_3) = 5 : 1$，设：
- $n(\text{NaClO}_3) = 1\text{ mol}$
- $n(\text{NaClO}) = 5\text{ mol}$

### 3. 应用化合价升降守恒（得失电子守恒）
1. **失电子总数（化合价升高总量）：**
   $$\Delta \text{Valence}_{+} = 5 \times (1 - 0) + 1 \times (5 - 0) = 5 + 5 = 10\text{ mol}$$
2. **得电子总数（化合价降低总量）：**
   还原产物只有 $\text{NaCl}$，化合价降低总数必等于 $10\text{ mol}$：
   $$n(\text{NaCl}) \times (0 - (-1)) = 10\text{ mol} \implies n(\text{NaCl}) = 10\text{ mol}$$

### 4. 得出最终比值
$$\frac{n(\text{NaCl})}{n(\text{NaClO}_3)} = \frac{10\text{ mol}}{1\text{ mol}} = 10 : 1$$

---

## 💡 备选解法：化学反应方程式叠加法
- 反应①（生成次氯酸钠）：$\text{Cl}_2 + 2\text{NaOH} = \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$
- 反应②（生成氯酸钠）：$3\text{Cl}_2 + 6\text{NaOH} = 5\text{NaCl} + \text{NaClO}_3 + 3\text{H}_2\text{O}$

为使 $\text{NaClO} : \text{NaClO}_3 = 5 : 1$，进行加权叠加（**反应① $\times 5$ + 反应② $\times 1$**）：
$$8\text{Cl}_2 + 16\text{NaOH} = 10\text{NaCl} + 5\text{NaClO} + \text{NaClO}_3 + 8\text{H}_2\text{O}$$
化学计量数之比即物质的量之比：
$$n(\text{NaCl}) : n(\text{NaClO}_3) = 10 : 1$$
